Admin controls

Control slots and leaderboard updates.

Set separate BR/CS timings, approve and edit registrations, publish payment and room QR details, and enter verified match results. In live server mode, changes appear for everyone immediately; shared live updates require the backend.

Unlock admin panel

Enter the admin PIN set in Render under TOURNAMENT_ADMIN_PIN. If you did not set that environment variable, the fallback PIN is 2026. Keep this PIN private.

Set match timings (independent BR and CS schedules)

Choose a start time, session duration, and gap between the three time-linked slots for each mode. Each BR slot contains 3 matches; each CS slot contains 1 match. Times are displayed in IST.

Update room slots

Set confirmed/filled entries for any room. Battle Royale lobbies have up to 12 entries/teams (slots 1–12). Clash Squad rooms have 2 teams.

Publish Room ID & Password

Share room details from here. If “release only when complete” is used, players will see details only after the room/lobby is full.

Payment instructions for players

Upload an optional payment QR and/or set a UPI ID. Players can use the QR or generated UPI link. The UTR/reference remains required, and payment still needs manual verification before approval.

Enter verified match results

For each approved BR entry, enter kills and placement position for each of the 3 matches. Points are calculated automatically from kills plus the placement table. For CS, select Win/Loss and enter round difference. Saving publishes last-match details and cumulative standings; BR final score is never typed manually.

How to control the website as admin

  1. Set schedules: select separate BR and CS start times, session lengths, and gaps. Three slots are retained for both modes; BR is 3 matches per slot and CS is 1.
  2. Verify payments: publish the payment QR and/or UPI ID above. Players submit their UTR/reference. QR/UPI is not an automatic payment gateway; manually verify the reference before approving.
  3. Review registrations: use Approve/Reject after checking the UTR. Edit names supports emoji and symbols; Remove deletes a registration and frees its reserved slot.
  4. Enter results: for BR, enter kills and placement for all three matches; the site calculates points from the placement table. For CS, choose Win/Loss and enter round difference. Save to publish cumulative standings and last-match details.
  5. Publish room access: enter the custom Room ID/password and optionally upload a room QR. Details remain hidden until full-room release or you force release.
  6. Use a shared backend: host server.py to share admin changes and registrations across visitors. Static GitHub Pages does not provide live shared storage by itself.

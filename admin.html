Control slots and leaderboard updates.

Set separate BR/CS timings, approve and edit registrations, publish payment and room QR details, and enter verified match results. In live server mode, changes appear for everyone immediately; shared live updates require the backend.

Admin sign-in

Use your private admin passphrase. The server verifies its PBKDF2-SHA256 hash from Render’s TOURNAMENT_ADMIN_PASSWORD_HASH environment variable. There is no default password and no offline admin mode.

Storage status will appear after the admin summary loads.

Set match timings (independent BR and CS schedules)

Choose a start time, session duration, and gap between the three time-linked slots for each mode. Each BR slot contains 3 matches; each CS slot contains 1 match. Times are displayed in IST.

How to control the website as admin

  1. Set schedules: select separate BR and CS start times, session lengths, and gaps. Three slots are retained for both modes; BR is 3 matches per slot and CS is 1.
  2. Verify payments: publish the payment QR and/or UPI ID above. Players submit their UTR/reference. QR/UPI is not an automatic payment gateway; manually verify the reference before approving.
  3. Review registrations: use Approve/Reject after checking the UTR. Edit names supports emoji and symbols; Remove deletes a registration and frees its reserved slot.
  4. Enter dated results: choose any match date from the calendar or date field. BR uses kills and placement for three matches; CS uses Win/Loss and round difference. Previous dates remain archived when a newer date is saved.
  5. Set leaderboard default: players can choose a saved date; select whether the page opens on latest match results or all-time totals.
  6. Use the calendar: click any day, including an empty day. Registration and saved-result states are shown separately; the selected date also loads into result entry.
  7. Keep storage durable: host server.py on persistent storage and configure TOURNAMENT_DATA_DIR. Free ephemeral storage can be cleared on redeploy/restart; check the status notice above.
  8. Manage room access: save the custom Room ID/password and optional QR. Details remain hidden until full-room release or you force release; Remove Saved Room Details unpublishes and deletes those credentials without changing registrations.

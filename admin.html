How to control the website as admin

  1. Change tournament text: edit data.js for event name, WhatsApp, UPI, date, fee tiers and prize notes.
  2. Update slots: unlock this page, set confirmed entries/teams for each room, then export state JSON.
  3. Update leaderboard: add score entries here. In live server mode it appears immediately on the public leaderboard.
  4. Publish room ID/password: use the Room ID & Password box. Players can view it on room-details.html after release.
  5. Make updates visible to everyone: open GitHub on your phone, edit data.js, paste the exported values into publishedState, and commit. GitHub Pages updates in 1–3 minutes.
  6. Collect real registrations centrally: connect Google Sheets/Firebase/Supabase later. Static GitHub Pages alone cannot collect every player’s entry in one admin account automatically.

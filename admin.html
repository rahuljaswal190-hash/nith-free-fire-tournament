Admin controls

Control slots and leaderboard updates.

Use this panel to approve teams, assign lobbies, enter final team scores, and publish room ID/password. In live server mode, your changes appear for everyone immediately. On static hosting, you still need a backend for true live updates.

Unlock admin panel

Enter the admin PIN set in Render under TOURNAMENT_ADMIN_PIN. If you did not set that environment variable, the fallback PIN is 2026. Keep this PIN private.

Update room slots

Set confirmed/filled entries for any room. Battle Royale lobbies have up to 12 entries/teams (slots 1–12). Clash Squad rooms have 2 teams.

Publish Room ID & Password

Share room details from here. If “release only when complete” is used, players will see details only after the room/lobby is full.

Registrations & approvals

Enter final scores for approved teams

Approved teams appear here automatically with their slot and team name. After matches, enter each team’s final combined score and select Save all scores. Battle Royale scores cover all 3 matches in the selected time window; Clash Squad scores cover its 1 match.

How to control the website as admin

  1. Change tournament text: edit data.js for event name, WhatsApp, UPI, date, fee tiers and prize notes.
  2. Approve entries: review a registration and tap Approve or Reject. Each entry gets a reserved lobby slot from 1–12 when submitted.
  3. Final scores: approve entries, enter each final score in the team table, and tap Save All Scores. The public leaderboard updates live.
  4. Publish room ID/password: use the Room ID & Password box. Players can view it on room-details.html after release.
  5. Make updates visible to everyone: open GitHub on your phone, edit data.js, paste the exported values into publishedState, and commit. GitHub Pages updates in 1–3 minutes.
  6. Collect real registrations centrally: connect Google Sheets/Firebase/Supabase later. Static GitHub Pages alone cannot collect every player’s entry in one admin account automatically.
